'---------------------------------------------------------------------------------------------------------
' AutoMod Instruction Script
'---------------------------------------------------------------------------------------------------------
' Configures module downloads, extraction, and organization for the AutoMod app.
'
' General Info:
' - Commands are executed sequentially from top to bottom.
' - All file operations are relative to the "modules_ext" directory.
' - Supported archives (e.g., ZIP) are automatically extracted.
' - Automatic backups are performed in specific scenarios to prevent data loss.
'
' Commands:
'
'   [!]DOWNLOAD = <url>, <module_name>
'     - Downloads and extracts <url> to <module_name> folder.
'     - GitHub repo links (e.g., "https://github.com/swoolcock/diddy") auto-extract to <module_name>.
'     - If <module_name> is omitted, uses repo or zip filename.
'     - Use ! to force overwrite existing files/folders.
'
'   [!]MOVE = <fromFolder>, <toFolder>
'   [!]COPY = <fromFolder>, <toFolder>
'     - Moves or copies <fromFolder> to <toFolder> (relative to "modules_ext").
'     - Example: "sdl2mixer\modules_ext\sdl2mixer", "sdl2mixer"
'     - Use ! to force overwrite existing folders.
'
'   MOVEC = <fromFolder>, <toFolder>
'   COPYC = <fromFolder>, <toFolder>
'     - Moves or copies contents from <fromFolder> to <toFolder> (relative to "modules_ext").
'
'   [!]DELETE = <fromFolder> | <filename>
'     - Deletes specified file/folder (downloaded items only by default).
'     - Use ! to force delete any file/folder.
'
' Usage Notes:
' - Use "!" prefix for force operations to overwrite existing content.
' - GitHub URLs are auto-detected and handled for seamless module extraction.
'---------------------------------------------------------------------------------------------------------
