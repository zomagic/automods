'---------------------------------------------------------------------------------------------------------
' This file serves as the instruction script for the AutoMod app.
' It defines which modules to download, extract, and organize.
'
' Available commands:
'
'   [!] DOWNLOAD = <url>, <module_name>
'       - It will downloads from <url> and unzip it into <module_name>.
'       - For GitHub modules, just provide the repo link, e.g.:"https://github.com/swoolcock/diddy"
'       - If <module_name> is not specified, the repo name or zip filename will be used.
'       - Add "!" before DOWNLOAD will force to overwrite if the folder or file already exists in your system.
'
'   [!] MOVE = <fromFolder>, <toFolder>
'   [!] COPY = <fromFolder>, <toFolder>
'       - Copies or moves a folder from one location to another.
'         <fromFolder> and <toFolder> are relative to "modules_ext" not an absolute paths.
'         Example: "sdl2mixer\modules_ext\sdl2mixer", "sdl2mixer"
'       - Add "!" before COPY or MOVE to force overwrite if the folder already exists.
'	DELETE = <fromFolder> | <filename>
'---------------------------------------------------------------------------------------------------------
